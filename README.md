# custom-pc-build
Complete documentation of a custom PC build: component selection, photos, and future upgrade plans

Component Selection:
- CPU - AMD Ryzen 7 5800X 8-Core Processor
- RAM - G.Skill Ripjaws 2x16 DDR4
- GPU - NVIDIA GeForce RTX 4060 (8GB)
- SSD - 2TB Samsung 990 PRO
- HDD - 3TB Hitachi
- Motherboard - ASUS PRIME B550M-A WIFI 2
- OS - Windows 10 Pro
- Monitor 1 - MSI G32C3W
- Monitor 2 - Sceptre F24
- CPU Cooler - Corsair 240mm AIO liquid CPU cooler
